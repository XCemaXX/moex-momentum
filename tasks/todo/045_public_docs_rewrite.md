# Публичные тексты: README, methodology, ограничения

> Создана 2026-09-05 по итогам сквозного ревью репозитория (13 линз, агенты). Объём M. Числа не меняются.

## Главная претензия по существу

`docs/methodology.md:89` утверждает про MCFTRR: «Совпадает с базой нашего расчёта,
прямое сравнение корректное».

Совпадает только **налоговая база**. Q-портфель равновзвешенный, ~25 имён; MCFTRR
капвзвешенный, в нём доминируют несколько голубых фишек. Часть того, что публикуется
как альфа Q1, — это эффект равного веса и малой капитализации, а не моментум. Документ
не умалчивает об этом, а прямо отрицает.

Второе неназванное ограничение: в издержках только комиссия 0.05% и налог 13%. Спреда
и проскальзывания нет — слово «спред» встречается только как «спред Q1−Q4». Ежемесячный
ребаланс равновзвешенного портфеля по хвосту top-100 российского рынка 2013 года
(медиана оборота сотой бумаги ~9 млн ₽/мес, цифра из того же документа) стоит по спреду
заметно больше комиссии.

## Структурное

1. **README на 36% состоит из runbook'а** (`README.md:52-131`), который вдобавок
   продублирован в `.claude/skills/update_monthly_data/references/*.md`, причём **там
   он подробнее**. При этом `SKILL.md:78-80` объявляет README каноном. Вырезать в
   `docs/RUNBOOK.md`, оставить три строки со ссылкой.
2. **Нигде нет результата.** Ни окна бэктеста, ни CAGR, ни спреда Q1−Q4, ни просадки.
   Человек с GitHub должен уйти на сайт и разглядывать график. Для проекта, чья
   ценность — эмпирический результат, это главная дыра. Добавить «Results at a glance»
   сразу после вводного абзаца.
3. **Ограничения размазаны** по буллетам раздела «Корпоративные действия» —
   `methodology.md:66,107,108,110,116`. Собрать в отдельный раздел «## Ограничения»
   перед «Источники данных». В README добавить «Limitations» из 5-6 однострочников
   **до** Quickstart. Сейчас там безусловное «**Survivorship-free.** No retrospective
   winners list» без единой оговорки.
4. **Нет дисклеймера.** При этом `methodology.md:75` прямо называет последнюю строку
   «actionable-инструкцией: портфель, который держится в течение месяца M». Публичная
   финансовая методика, предлагающая торговый состав, без оговорки о применимости.
   MIT покрывает софт, не содержание. Две строки в README перед License и в футер
   `base.html`.
5. **«Индекс магов» — целая вкладка сайта**, о которой ни README, ни methodology не
   знают. Читатель открывает сайт и видит незнакомый пункт меню.
6. **Quickstart даёт неполный рецепт**: три команды против шести в `pages.yml`.
   Результат — сайт без работающей страницы Experiments. И этот же рецепт напечатан
   ниже второй раз, в другой версии.
7. **README не показывает, как проверить код.** `pytest`, `ruff check`, `mypy src` не
   встречаются ни разу, хотя это ровно то, что гоняет `lint.yml`.
8. **Языковой разрыв не объявлен**: README английский и подаёт `docs/methodology.md`
   как «Methodology (full)», читатель кликает и попадает в русский текст.
